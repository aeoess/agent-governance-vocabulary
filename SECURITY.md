# Security Policy

This repository holds the Agent Governance Vocabulary: the vocabulary file, the crosswalk records contributed by implementers, and the validators and CI that check them. Security issues here are issues in those validators, the CI that runs them, or the integrity of the records they admit.

## Reporting

Report privately: https://github.com/aeoess/agent-governance-vocabulary/security/advisories

Email: security@aeoess.com

Please include a description, steps to reproduce, and the impact you see. Please do not open a public issue for a security report.

## Supported

The `main` branch. The vocabulary is versioned in the file itself; crosswalk records carry their own maintainer confirmation and are not security-supported artifacts of this repository.

## Disclosure

Coordinated: a fix lands before the report is published, and the published advisory names the affected validator or workflow and the commit that fixed it. Advisories for the Agent Passport System SDKs are published in their own repositories.
